# FraudShield Research

This repository reproduces and extends the baseline results reported by Vidros et al. (2017), Naudé et al. (2023), and Pillai (2023) on the Employment Scam Aegean Dataset (EMSCAD), commonly distributed as the "Real or Fake Job Posting Prediction" dataset on Kaggle. The current codebase represents **Stage 1** of a larger multi-stage pipeline: it handles dataset acquisition, data auditing, and preliminary exploratory analysis. Subsequent stages will add feature engineering, model training with cross-validated seed repeats, and a full evaluation harness.
